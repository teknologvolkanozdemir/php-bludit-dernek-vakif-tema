# Dayanışma — Bludit teması

Vakıf ve dernekler için sıcak, modern ve erişilebilir bir Bludit teması. Mobil uyumlu sayfalar, içerik kartları, sade gezinme ve klavye kullanıcıları için atlama bağlantısı içerir. Tema harici yazı tipi, JavaScript veya CSS kütüphanesi kullanmaz.

## Kurulum

1. Bu depoyu indirin.
2. Tema klasörünü Bludit kurulumunuzdaki `bl-themes/dayanisma` dizinine kopyalayın.
3. Yönetim panelinde **Ayarlar → Tema** bölümünden `dayanisma` temasını etkinleştirin.
4. Site başlığınızı, sloganınızı ve açıklamanızı Bludit ayarlarından düzenleyin; statik sayfalar ana gezinme menüsünde görünür.

Tema Bludit 3.x ve 4.x için hazırlanmıştır. Türkçe arayüzü hedefler; ziyaretçi içeriğini Bludit düzenleyicisinden yönetebilirsiniz.

## Erişilebilirlik

- Sayfa başında klavyeyle erişilebilen ana içeriğe geçiş bağlantısı bulunur.
- Semantik başlıklar, gezinme alanı ve ana içerik kullanılır.
- Klavye odağı görünürdür; gezinme geçerli sayfayı `aria-current` ile belirtir.
- Dar ekranlar, azaltılmış hareket tercihi ve yüksek kontrast/forced-colors modu desteklenir.
- Dekoratif simgeler ekran okuyuculardan gizlenir; içerik görsellerine boş alt metin verilir.
